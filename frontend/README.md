# AlphaSignal React UI

## Pages
- **Dashboard** — Live price cards, candlestick chart, model performance, volume analysis
- **Signals**   — Real-time ML signals with search, add/remove tickers, sorting, filtering
- **Backtest**  — Strategy backtesting with equity curve and monthly returns
- **Alerts**    — Send SMS/Email alerts, manage users, view history
- **Settings**  — Retrain models, API reference, platform info

## Tech Stack
React 18 · Vite · Recharts · Tailwind CSS · React Router · Axios

## Quick Start
```bash
npm install
npm run dev      # → http://localhost:3000
npm run build    # → dist/ folder for production
```

Requires FastAPI backend running on port 8000.
